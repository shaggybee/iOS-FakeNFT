# FakeNFT

Командный дипломный проект Яндекс Практикума: приложение для просмотра NFT, управления коллекцией, избранным и корзиной.

SwiftUI · MVVM · iOS 17.0+ · async/await.

## Запуск

Откройте `iOS-FakeNFT-Extended.xcodeproj` и выберите схему `iOS-FakeNFT-Extended`.
Для настоящего API скопируйте `Configurations/Secrets.xcconfig.example` в `Configurations/Secrets.xcconfig` и укажите учебный `API_TOKEN`. Файл с токеном исключён из Git.

В Debug профиль по умолчанию использует локальные демонстрационные данные. Для проверки профиля, каталога и корзины с одним серверным профилем добавьте аргумент запуска `--profile-live-api`. В Release профиль всегда работает с API. Ошибки сети отображаются с возможностью повтора.

## Профиль

Просмотр и редактирование данных пользователя, открытие сайта во встроенном браузере, список «Мои NFT» с сохранением сортировки, избранное и обновление счётчиков. Во время переходов между вкладками используются общий контейнер сервисов и общий сетевой клиент.

[Скринкаст всего эпика в объединённом приложении](docs/profile/screencast/profile-epic.mp4) · [Декомпозиция](docs/profile-decomposition.md) · [Таск-трекер](https://github.com/users/shaggybee/projects/1).

Скринкаст записан с локальными данными профиля: он демонстрирует интерфейс и обработку ошибок без изменения общего серверного профиля.
