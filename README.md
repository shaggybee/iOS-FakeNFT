# FakeNFT

Командный дипломный проект Яндекс Практикума: приложение для просмотра NFT, управления коллекцией, избранным и корзиной.

SwiftUI · MVVM · iOS 17.0+ · async/await.

## Запуск

Откройте `iOS-FakeNFT-Extended.xcodeproj` и выберите схему `iOS-FakeNFT-Extended`.
Для настоящего API скопируйте `Configurations/Secrets.xcconfig.example` в `Configurations/Secrets.xcconfig` и укажите учебный `API_TOKEN`. Файл с токеном исключён из Git.

В общей схеме Xcode включён аргумент `--profile-live-api`: профиль, каталог и корзина используют настоящий API. Для демонстрации профиля без сети отключите этот аргумент в схеме Debug — будут использованы локальные данные. В Release профиль всегда работает с API. Ошибки сети отображаются с возможностью повтора.

## Профиль

Просмотр и редактирование данных пользователя, открытие сайта во встроенном браузере, список «Мои NFT» с сохранением сортировки и переключением избранного по сердцу, избранное и обновление счётчиков. Тексты интерфейса, валидации и ошибок профиля переведены на русский и английский. В редакторе клавиатура скрывается при потере фокуса, нажатии вне поля или по кнопке «Готово». Во время переходов между вкладками используются общий контейнер сервисов и общий сетевой клиент.

[Декомпозиция](docs/profile-decomposition.md)

Скринкаст записан с локальными данными профиля: он демонстрирует интерфейс и обработку ошибок без изменения общего серверного профиля.
