# Эпик «Профиль» — Антон / AntonA22

Статус плана: подготовлен для проверки наставником; одобрение пока не получено.

SwiftUI, MVVM (`@Observable`), iOS 17.0+, Swift Concurrency. Сервисы — `actor`, модели — `Sendable`, UI — `@MainActor`. Общая доска: https://github.com/users/shaggybee/projects/1.

Каждая итерация создаётся отдельной веткой от `epic/profile`. Накопительный PR эпика направляется в `develop`. Названия веток итераций: `feature/profile-iteration-1`, `feature/profile-iteration-2`, `feature/profile-iteration-3`.
