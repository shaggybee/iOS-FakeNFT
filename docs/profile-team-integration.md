# Профиль в командном проекте

PR #93 принят ревьюером и влит в epic/profile. Профиль подключён к общей панели вкладок вместе с каталогом и корзиной через один ServicesAssembly из AppRootView. В актуальной общей схеме стартовая вкладка — профиль, а аргумент --profile-live-api включён; UI-тесты используют явный изолированный режим.

При объединении сохранены сервисы коллекций, избранного, заказов, валют и корзины. Сетевой клиент поддерживает JSON DTO и form-urlencoded с повторяющимися ключами. Общая модель Nft использует командный Double и поле description; отсутствие описания в старых тестовых данных допустимо. Сервис NftService сохраняет пакетный метод загрузки для корзины.

Рекомендации ревьюера про локаль цены и новые избранные NFT после удаления обработаны. Если обновление снимка после подтверждённого PUT завершилось ошибкой, повтор загружает данные и не повторяет мутацию.

Проверка: 56 unit-тестов без ошибок; 15 UI-сценариев прошли в полном прогоне, сценарий обычного запуска повторён после адаптации к стартовой вкладке каталога и прошёл отдельно. Всего подтверждены 16 UI-сценариев. Release-сборка успешна.

[Скринкаст всего эпика](profile/screencast/profile-epic.mp4): профиль, редактирование, обработка недоступного сайта, мои NFT, сортировка, избранное, удаление последнего NFT и счётчик. Видео записано на локальных данных, без изменения общего серверного профиля.

Прямой доступ из симулятора к серверу по-прежнему зависит от локальной сетевой среды. В прежней диагностике настоящий профиль и избранное успешно загружались через временный localhost CONNECT-прокси; этот прокси не включён в приложение. Живые PUT не выполнялись. Для реальной общей сессии профиля, каталога и корзины используйте --profile-live-api и учебный API_TOKEN.

Итоговый командный PR #94 (develop → main) должен быть дополнен статистикой её автором до финальной сдачи.


## Замечания команды — 09.11.2026

В «Моих NFT» добавлено переключение избранного с обновлением сердца, счётчика профиля и списка избранного. Сервис перечитывает свежие likes перед изменением, а повтор задаёт то же желаемое состояние.

В редакторе введён FocusState для полей имени, описания и сайта. Нажатие вне поля, по заголовку, по «Готово», сохранение и уход с экрана снимают фокус; интерактивное скрытие при прокрутке сохранено. Переход между полями не блокируется.

Оставшиеся тексты профиля, редактора, сайта, accessibility, валидации и ошибок перенесены в Localizable.strings для ru/en. Названия и счётчики меню локализуются, цена NFT учитывает локаль окружения. Пользовательские данные не переводятся. README уточняет включённый в общей схеме режим настоящего API.

62 unit-теста прошли в полном прогоне. В нём прошли 20 UI-сценариев, включая две новые проверки английского интерфейса; тест клавиатуры сначала нажал на строку состояния из-за полноэкранных координат ScrollView. После привязки точки к видимой форме сценарий отдельно прошёл. Итого подтверждены все 21 UI-сценарий. Результаты — work/ProfileLocalizationKeyboard.xcresult и work/ProfileKeyboardVerified.xcresult, снимки проверены визуально. Release-сборка iOS Simulator успешна (work/profile-localization-keyboard-release.log). Настоящие данные API не изменялись.
